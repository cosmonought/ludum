# ProjectsIndex

/projects/ — the catalogue. Every project as a **CatalogueEntry** row in catalogue order, with status filters above and the status key below.

- Title at d1 with the count; one sentence.
- **Tabs** as filters (`data-ld-filter="catalogue"`): All · Playable · In development · Experimental · Research · Archive, each with its count. Filtering updates the live count; an empty filter shows the empty state, which says why.
- Rows are the whole link; hover wipes `paper-2` across and prints the project's picture beside the title.
- **What the statuses mean**: the five stamps with one sentence each — the same words as **StatusStamp**.
- The **PlayBand** closes the page above the footer.
- No grid of cards, no sort menus, no search: the catalogue is short and ordered on purpose.
